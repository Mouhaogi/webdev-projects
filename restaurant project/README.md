# Le Baobab — Restaurant Website

Le Baobab is a fictional Senegalese restaurant website created as a student web development project.

The website introduces the restaurant, presents traditional Senegalese food, and includes a demonstration reservation form.

## Pages

- **Home (`index.html`):** Restaurant introduction and featured dishes.
- **Our Menu (`menu.html`):** Dishes, descriptions, prices, and category filters.
- **Book a Table (`reservation.html`):** A form that simulates a table reservation. It does not send or store real bookings.

## Technologies

- **HTML:** Page structure and content.
- **CSS:** Visual design and responsive layout.
- **JavaScript:** Mobile navigation, menu filtering, and reservation confirmation.
